## Summary

This release turns CollectZ workspace ownership from scattered conventions into a reviewed, machine-checked contract. It classifies every fresh-install table and maintained Express route, records same-workspace foreign-key expectations, certifies important jobs and provider paths, centralizes stable permission keys for workspace membership management, and adds live cross-workspace authorization proof.

## What changed

- Added a generated and reviewed ownership snapshot covering all fresh-install database tables, maintained route declarations, stable permission keys, and selected non-request execution paths.
- Table entries identify their ownership category, authoritative ownership key, rationale, and same-workspace foreign-key expectations.
- Authenticated route entries record method, ownership/locality, stable read or mutation permission, scope source, CSRF policy, and session-credential requirement.
- Added stable account, platform, workspace, content, member, and integration permission keys with owner/admin/member/viewer role bundles that reject unknown permissions.
- Routed workspace membership-management decisions through the stable permission evaluator while retaining the existing role assignment hierarchy.
- Certified durable sync jobs, Plex webhook/reconciliation/readback, capture OCR, valuation, workspace export, media search, activity audit, and provider-backed repair paths against explicit workspace sources.
- Added a live PostgreSQL-backed authorization smoke for anonymous denial, read-only mutation denial, sibling-workspace read/mutation/provider denial, identifier tampering, and durable-job isolation.
- Added ownership snapshot drift and live authorization certification to the maintained RBAC CI job.

## Breaking changes

- No public API response contract is intentionally removed.
- New tables, route declarations, permissions, or maintained execution paths must be classified and the reviewed contract snapshot regenerated before CI will pass.
