## Summary

Adds a read-only preview of approved BookOrbit and Kavita metadata differences, showing which fields are currently eligible for a future update and why other fields remain blocked.

## What changed

- Added a targeted workspace-authorized preview for one immutable provider observation attached to the current media record.
- Recomputes the current comparison, latest review fingerprints, and field locks at request time.
- Marks only current approved and unlocked differences eligible.
- Reports explicit blockers for unreviewed, outdated, rejected, deferred, otherwise unapproved, and locked fields.
- Adds an operator-facing preview in Library Provider history with eligible and blocked counts.
- Keeps the contract strictly read-only with `mutationEnabled: false`; no metadata, authority, provider identity, or review state is changed.
- Keeps each import deduplication advisory lock on one database session so concurrent provider/scheduler work cannot strand a lock in the connection pool.

## Breaking changes

None. The new endpoint and Provider history preview are additive.

## Security vulnerability triage

- High findings: backend and frontend production dependency audits must report zero blocking vulnerabilities.
- Authorization impact: preview reads execute only inside the authorized media workspace/library transaction and return `404` outside that scope.
- Evidence hygiene: preview readback omits workspace ids, library ids, actor ids, credentials, endpoints, raw payloads, and internal control connection ids.
- Owner: CollectZ maintainers.
- Target remediation milestone: `3.29.9` before release publication.

## Known issues and follow-up
