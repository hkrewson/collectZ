## Summary

Extends reviewed provider observation apply to credential-safe BookOrbit and Kavita cover references, with a visual current-versus-provider comparison and the existing exact-plan, preserve-only, and immutable-audit protections.

## What changed

- Added `media.poster_path` to the observation comparison allowlist only for exact CollectZ-owned BookOrbit or Kavita proxy paths.
- Reconstructs eligible historical BookOrbit cover candidates from immutable connection, identity, and observed cover-version evidence without a data backfill.
- Rejects direct upstream, cross-origin, malformed, unsupported-provider, and identity-mismatched cover values.
- Added responsive current, observed, proposed, previous, and applied cover previews with understandable missing-image and load-failure states.
- Reuses explicit approve/reject/defer review, exact-plan confirmation, atomic apply, reviewed preserve-only field authority, and immutable before/after history.
- Keeps provider refresh, provider selection, identity rematching, automatic cover replacement, and provider image-byte import out of scope.

## Breaking changes

None. Cover review is an additive extension of the existing provider observation comparison and apply contracts.

## Environment/config changes

None.

## Migration and data impact

No migration. Existing observations can yield a BookOrbit cover candidate only when their immutable facts already contain sufficient native cover evidence. Applying a reviewed cover changes only `media.poster_path` and its existing Canonical Field Control and apply-event records.

## Rollback guidance

Deploy the matching `3.29.10` backend and frontend together. No schema rollback is required. Existing reviewed cover apply events remain immutable history; restore a prior cover deliberately through the normal media editor if needed.

## Known issues and follow-up

Cover apply stores a reviewed CollectZ proxy reference; it does not copy image bytes into local uploads. Automatic rematching, provider writeback, automatic cover refresh, and work/edition/owned-copy modeling remain separate future work.
