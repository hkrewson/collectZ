# collectZ v3.25.0

## Version and date

- Version: `3.25.0`
- Date: `2026-10-16`

## Milestone target and status

- Roadmap slice: `3.25.0 — Apple TV Device Authorization and Read-Only Client`
- Status: implementation and local verification in progress; signed TestFlight and hardware acceptance remain external gates.

## Summary

Adds a native Apple TV companion for CollectZ with browser-approved sign-in, read-only collection browsing, and the existing CollectZ visual identity. The SwiftUI client is maintained in the sibling `collectZ-tvos` repository.

## What changed

- TV pairing and browsing work in both deployment modes, including installations with Cairn. Every read still requires current library/workspace membership; archived workspaces are excluded.
- Native screens use only the CollectZ name. Debug simulator builds recognize bare localhost and private IPv4 LAN addresses as HTTP; public connections and Release builds still require HTTPS.

- Browser `/activate` approval uses short-lived device codes, existing cookie authentication, and CSRF protection. Device credentials/codes are hashed; polling is limited and redemption is atomic.
- Dedicated TV permissions reuse mobile access/refresh sessions. Existing scanner permissions are unchanged. TV sessions cannot edit data, trigger imports, or use capture APIs.
- Explicit library selection checks current membership on every read, including administrator accounts, without changing the web application's active library.
- TV responses expose safe metadata and authorized artwork paths rather than raw integration payloads or source URLs. Collection joins check linked media ownership.
- Native tvOS 18+ screens use CollectZ's colors, logo, bundled fonts, cards, and badges, with remote focus, accessible labels, stale states, and Keychain credentials.
- Updated compatible axios and proxy-addr lockfile resolutions to remove production dependency advisories identified during release validation.

## Breaking changes

None for existing web or scanner clients. Apple TV requires CollectZ 3.25.0+ and capability version 1. Both deployment modes support the same read-only TV client, including installations with Cairn.

## Environment/config changes

No new required backend environment variables. Apple TV requires a trusted HTTPS CollectZ origin. The app's debug-only loopback/private IPv4 HTTP allowance supports isolated simulator tests; Release builds require HTTPS.

## Migration and data impact

Migration 123 adds `tv_device_authorizations`; it does not alter collection data. The initialization reference and ownership inventory include the new table. Existing mobile sessions retain their scopes.

## Deployment and verification

Run the normal migration service before backend startup. Version metadata and Help > Releases are synchronized. Canonical `collectz-private` runtime checks, dedicated disposable-Core pairing/isolation tests, native simulator/device builds, browser approval tests, and applicable release gates are recorded in `docs/wiki/61-Apple-TV-Client.md` and the native verification document. Failed or unavailable gates remain release blockers; a compiled archive is not evidence of signed distribution.

## Rollback guidance

Restore the previous backend/frontend image versions together. The added device-authorization table can remain unused; collection tables are unchanged. Revoke TV sessions when withdrawing device support. Restore a pre-upgrade database backup if a full schema rollback is required; never discard collection data to roll back the client.

## Known issues and follow-up

- TestFlight upload, owner signing configuration, beta-review access, and physical Siri Remote/VoiceOver acceptance require owner-provided account/hardware access.
- Unsupported external artwork hosts show a placeholder; direct source-service access is never delegated to the TV.
- Offline sign-out clears local credentials immediately; remote revocation cannot be confirmed while the server is unavailable.
- Release readiness is conditional on the verification record and mandatory CI/security gates.
