## Summary

Updates the application runtime, provider HTTP transport, rate limiting, mail transport, object-storage client, and frontend build tooling before provider-identity and BookOrbit implementation resumes.

## What changed

- Updated Express from `5.2.1` to `5.3.0` and express-rate-limit from `8.7.1` to `8.7.2`.
- Updated backend Axios from `1.20.0` to `1.21.0` before BookOrbit begins using the shared provider HTTP seam.
- Updated Nodemailer from `10.2.1` to `10.3.1` and AWS SDK S3 from `3.1156.0` to `3.1162.0`.
- Updated frontend esbuild from `0.28.1` to `0.28.2` without changing Vite, Vitest, React, Tailwind, or ZXing.
- Kept the existing security overrides until the installed graph proves they are no longer required.

## Breaking changes

No intended application API, database, or user-facing contract changes. Axios `1.21.0` changes some header-default handling, so provider/auth HTTP behavior is explicitly included in release verification.

## Environment/config changes

None.
