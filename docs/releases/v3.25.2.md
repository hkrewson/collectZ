# collectZ v3.25.2

## Version and date

- Version: `3.25.2`
- Date: `2026-10-21`

## Milestone target and status

- Roadmap slice: `3.25.2 — Build Tool Dependency Security Fixes`
- Status: complete; hosted release gates passed and tag `v3.25.2` exists on origin.

## Summary

Remediates reported vulnerabilities in CollectZ's development and build tooling. Vite and its source-map dependency are upgraded to fixed releases, and the backend development command now uses Node's built-in watch mode instead of Nodemon and its affected watcher tree.

## What changed

- Upgrade frontend Vite from affected `8.0.16` to `8.3.5` and lock `source-map-js` to `1.2.2`, addressing the reported Vite/launch-editor and source-map-js advisories.
- Replace `nodemon server.js` with `node --watch server.js` and remove Nodemon from backend development dependencies. This removes the backend watcher chain that included vulnerable `braces` and `brace-expansion` packages.
- Keep backend and frontend production dependencies on the previously patched `follow-redirects@1.16.1`.
- Synchronize app metadata and Help > Releases to `3.25.2`.

## Breaking changes

No API or data contract changes. The backend `npm run dev` command uses Node's built-in watch mode, so maintainers need the supported Node `24.22.1` baseline recorded in `.nvmrc`.

## Environment/config changes

No new environment variables or deployment configuration.

## Migration and data impact

No database migration or data change.

Full clean backend and frontend dependency audits report zero vulnerabilities. Hosted Build and Publish Images run `39647603870` and CodeQL run `39647603735` passed, including dependency, secret, migration, compose smoke, RBAC, browser, runtime, image security/SBOM, release preflight, and auto-tag gates.

## Security vulnerability triage

- High findings: `0` after complete backend and frontend `npm audit` runs, including development dependencies.
- `source-map-js` versions below `1.2.2` can block the event loop on specially crafted indexed source maps; both current dependents now resolve `1.2.2` (`GHSA-68fv-2mgg-jv7q`).
- The project's Vite `8.0.16` was within affected ranges for three `launch-editor` advisories involving Windows command escaping, editor CLI argument handling, and executable checks; Vite is now `8.3.5`, beyond the published Vite `8.3.3` fixes (`GHSA-698v-4r3x-3vcv`, `GHSA-r825-w8mm-5pxw`, `GHSA-587h-7wmj-h5pm`).
- Backend Nodemon depended on vulnerable `braces`/`brace-expansion` watcher paths. Removing Nodemon and using Node's built-in watch mode removes those dependencies from the backend install. Backend and frontend full audits both report zero findings after clean installs.
- These findings were in build/development tooling. The deployed frontend is static Nginx content, and Nodemon was not part of the backend production install; this patch also clears them from maintainer and CI dependency trees.
- Owner: CollectZ maintainers.
- Target remediation milestone: `3.25.2`.

## Rollback guidance

If the updated Vite toolchain or Node watch mode causes a development workflow regression, restore the previous development command only after selecting a supported, audit-clean watcher dependency. Do not restore vulnerable package versions.
