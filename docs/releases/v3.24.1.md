## Version and date

- Version: `3.24.1`

## Milestone target and status

- Roadmap slice: `3.24.1 - Browser Capture Review Import`
- Status: `implementation complete; hosted release gates pending`

## Summary

This release lets a title-only browser-extension capture complete Capture Inbox review as a normal library import after the reviewer chooses its media type.

## What changed

- Added a compact library-type selector and explicit Add to library action for titled captures without lookup matches.
- Added Book, Comic, Movie, TV, Audio, and Game as supported review-import targets.
- Reused the existing media enrichment, deduplication, creation, and linking pipeline.
- Kept the stored capture title authoritative during title-only review imports.
- Recorded the chosen object type and title-review import provenance on converted captures.
- Documented the title-only capture-review API contract and added backend and browser regression coverage.

## Breaking changes

- None.

## Environment/config changes

- No new environment variables or provider credentials are required.

## Migration and data impact

- No database migration is introduced.
- Existing capture items are unchanged until a reviewer explicitly imports, converts, or discards them.
- A completed title-review import updates the capture status, linked media ID, object type, review decision, source context, and conversion timestamp.
