## Summary

Makes Movies and Games heading counts authoritative and immediately consistent after deletion while preserving collection cards in their aggregate library views.

## What changed

- Aggregate Movies and Games counts now add the server-reported media total to the server-reported collection total instead of counting only collection rows loaded on the current page.
- The heading count is withheld while its required media and collection result generations are unsettled, avoiding transient mixed-search totals.
- Collection requests use sequencing so a slower response from an older search cannot overwrite the active result set or count.
- Successful single deletion now updates media total, total pages, current page, and `hasMore` with the same shared pagination logic used by bulk deletion.
- Server-backed Library pages clamp when deletion or filtering removes the final result from the last page.
- Focused unit and browser coverage proves aggregate count composition, immediate deletion delta, reload persistence, stale-response rejection, and exact-title absence.

## Breaking changes

None. Backend routes, deletion authorization, collection membership behavior, and existing API response shapes are unchanged.

## Environment/config changes

None.

## Migration and data impact

No database migration or retained-data transformation is introduced. The current schema remains migration `144`. Browser fixtures create isolated user/library records and remove their media and collection test content after verification.
