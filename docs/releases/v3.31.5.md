# collectZ v3.31.5

## Version and date

- Version: `3.31.5`
- Date: `2026-11-27`

## Milestone target and status

- Roadmap slice: `3.31.5 — Safe Partial Batch Apply`.
- Status: complete locally; hosted certification awaits an authorized push.

## Summary

Prevents review actions from closing an incomplete Blu-ray collection traversal and keeps unapplied editions visible after an incremental apply.

## What changed

- Rejects Apply while collection traversal is collecting or paused.
- Disables Apply in the review drawer until the batch is ready and explains the wait.
- Recomputes lifecycle state after each apply from converted rows, remaining review decisions, enrichment failures, and apply failures.
- Keeps a partially applied batch ready and visible with successful conversions preserved.
- Marks the batch completed only after no pending review or failed enrichment remains.

## Breaking changes

None. Browser companion `0.3.2` remains compatible and unchanged.

## Environment/config changes

None.

## Migration and data impact

No database migration is required. Existing completed batches and imported Work, Edition, Owned Copy, and observation records are unchanged. The lifecycle correction applies to subsequent batch actions.
