## Summary

Adds a read-only, exact-library preview of possible canonical targets for an existing BookOrbit External Identity, using bounded observation evidence and explicit conflict blockers without moving anything.

## What changed

- Added deterministic candidate discovery from explicit BookOrbit provider identifiers, normalized ISBN, book title/author, and comic series/issue/volume evidence.
- Restricts discovery to the active workspace and exact library, excludes the currently attached record, and returns no internal identity ids or provider configuration.
- Labels candidate confidence, matched evidence, and conflicts such as mismatched identifiers, ISBN, media type, comic position, or an existing different BookOrbit identity.
- Added a compact read-only Identity match preview to Library Provider history, including loading, empty, eligible, and blocked states.
- Fingerprints the immutable observation and candidate state for a later reviewed-rematch contract while keeping `mutationEnabled` false.

## Breaking changes

None. The endpoint and interface are additive and read-only.

## Environment/config changes

None.

## Migration and data impact

No migration and no data mutation. Candidate discovery reads existing provider observations, canonical media, and External Identity state inside the authorized exact-library transaction.
