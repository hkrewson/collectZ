- Roadmap slice: `3.24.5 - Workspace Integration Scope Enforcement`
- Status: `implementation and local verification complete; hosted release gates pending after push`

## Summary

This release makes the active workspace integration row authoritative for provider saves and Plex automation. It removes silent installation-row Plex credential fallback, persists workspace Plex reconciliation/readback/writeback controls, and sends the Core/homelab provider screen to the active workspace endpoint.

## What changed

- Workspace integration saves now persist Plex reconciliation, watched/rating readback, and rating/watch-state writeback controls.
- Plex scheduler enablement and cadence are resolved from enabled workspace integration rows unless an explicit environment override is present.
- Scheduled Plex work filters out workspaces that have not enabled the corresponding automation.
- Workspace Plex execution no longer fills missing URL, credential, or section values from installation row `id=1`.
- Core/homelab provider settings and Plex writeback readback use `/api/spaces/{id}/integrations` for the active workspace.
- OpenAPI now documents all implemented workspace provider diagnostic endpoints and the Plex automation/writeback request and response fields.
- Added focused source and Docker runtime coverage for workspace persistence, unchanged installation state, and workspace-derived scheduler configuration.

## Breaking changes

- Workspace Plex execution no longer inherits connection credentials from the legacy installation integration row. A workspace that uses Plex must have its own saved Plex connection or an explicit supported environment configuration.

## Environment/config changes

- No new environment variables are required.
- Existing explicit Plex scheduler environment overrides remain authoritative when present.
- The canonical development stack remains `collectz-private` on port `3201`.

## Migration and data impact

- No schema migration is required. Existing workspace Plex automation columns are now written and consumed consistently.
- Existing installation-row values are preserved for compatibility but are no longer used as implicit workspace Plex credentials or scheduler settings.
