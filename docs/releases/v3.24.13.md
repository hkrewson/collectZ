## Summary

This maintenance release restores trustworthy dependency monitoring and main-branch release validation. It repairs Node 24 clean installs, remediates known production and tooling dependency findings, preserves Dependency Watch evidence when installs fail, and keeps migration rehearsal valid when identity certification is already current.

## What changed

- Updated backend CSV parsing, upload handling, mail delivery, rate limiting, IP parsing, and query-string parsing dependencies to remediated releases.
- Updated frontend Vitest and refreshed root tooling transitive dependencies so clean Node 24 audits cover all three lockfiles without known vulnerabilities.
- Added root tooling to Dependency Watch and made the workflow run for dependency-changing pull requests.
- Kept later Dependency Watch report and artifact steps running after an earlier ecosystem failure, so a broken lockfile no longer erases the diagnostic evidence.
- Changed generic migration rehearsal to select the latest real upgrade boundary while leaving identity-upgrade certification anchored to its reviewed policy marker.
- Restored direct commits to `main` as the default CollectZ delivery workflow; pull requests remain available when explicitly requested or operationally necessary.
- Serialized same-email registration attempts so concurrent Core self-registration returns one success and one deliberate conflict instead of leaking a database uniqueness failure as an internal error.
- Made the authentication abuse smoke edition-aware: Core proves invite tokens are ignored, while the platform contract continues to prove atomic one-time invite claims and replay rejection.
- Restored Core workspace-owned integration readback by deriving its internal workspace scope from the active library while keeping workspace identifiers hidden from the homelab user contract.

## Breaking changes

- None expected. The dependency upgrades preserve the existing application and API contracts.

## Environment/config changes

- No new environment variables.
- Node 24 remains the supported dependency-install and CI baseline.
- The canonical development stack remains `collectz-private` on port `3201`.

## Migration and data impact

- No database migration is added.
- Generic CI migration rehearsal now exercises migration `121 -> 122` when migration `122` is both the latest migration and the reviewed identity-certification baseline.
- Identity-upgrade certification continues to use baseline `122` and may report `not_required` when there is no newer identity-sensitive migration.
